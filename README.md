# Парсер вакансий с hh.ru

Проект для сбора и анализа данных о вакансиях с сайта hh.ru с использованием публичного API. Данные сохраняются в PostgreSQL, предоставляется удобный интерфейс для анализа.

## 📋 Функциональность

- Получение данных о 10+ компаниях-работодателях через API hh.ru
- Автоматическое создание базы данных и таблиц в PostgreSQL
- Сохранение информации о компаниях и их вакансиях
- Анализ данных через класс `DBManager`:
  - Список компаний с количеством вакансий
  - Список всех вакансий с деталями
  - Средняя зарплата по всем вакансиям
  - Вакансии с зарплатой выше средней
  - Поиск вакансий по ключевому слову

## 🛠 Технологии

- **Python 3.9+**
- **PostgreSQL** - база данных
- **psycopg2-binary** - драйвер для работы с PostgreSQL
- **requests** - для работы с API hh.ru
- **python-dotenv** - управление переменными окружения
